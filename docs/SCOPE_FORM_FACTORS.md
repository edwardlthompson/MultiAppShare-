# Form factor scope (Milestone **K.1**)

**Phones and tablets** are in scope for layout and testing. The app does **not** target Android TV or Wear OS (see **BUILD_PLAN** product scope).

**Large screens / split-screen:** UI should remain usable on tablets and multi-window where the OS allows resized activities; issues found on specific devices should be tracked as bugs. Day-to-day validation is **phone-first** unless you explicitly expand the release matrix.
